Maintenance Actions

These actions modify files on the SD card and upload state. Each action requires confirmation before proceeding.

Reset Upload State
Clears upload tracking so all days re-upload from the beginning
Delete All EDF Files
Removes all EDF and related files from SDCARD/ (session data preserved)
Recreate EDFs from Sessions
Deletes all EDFs and re-exports the newest days within the upload window
Reset ALL (Destructive)
Deletes everything under /somnotrace/ (SDCARD + .somnotrace) and clears upload state
Format SD Card (Destructive)
Formats the SD card to FAT32. ALL data is permanently erased — no recovery possible
Soft Reboot
Restarts the device without changing any settings
